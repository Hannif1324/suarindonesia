STRIX-001

Kebocoran Password Plaintext Database di Bundle Klien

CRITICAL (CVSS 9.8)

Berkas js/services/supabase-client.js baris 17 secara terang-terangan memuat komentar kata sandi akun database:

// supabase pasword: SU4R#!23A

Dampak: Pengambilalihan basis data Supabase secara penuh, manipulasi tabel, atau kebocoran data sensitif warga.

Remediasi: Hapus baris komentar tersebut dan lakukan rotasi kata sandi database pada Supabase Cloud dashboard segera.

STRIX-002

DOM/Stored XSS pada Reader Preview Modal

HIGH (CVSS 8.2)

Pada admin/js/article-editor.js (openReaderPreviewModal), input judul, ringkasan, dan penulis langsung diinterpolasikan ke dalam previewBody.innerHTML tanpa sanitasi DOMPurify.

<h1>${title}</h1> <!-- Input <img src="x" onerror="alert(1)"> langsung tereksekusi saat klik Pratinjau Pembaca -->

Bukti Pengujian: Terverifikasi di Chrome DevTools dengan pesan log msgid=5 [log] xss-title-img.

Remediasi: Terapkan this.sanitizeHtml(title) sebelum di-render ke modal HTML.

STRIX-003

Stored XSS & Paparan PII Warga pada Modul Pengaduan

HIGH (CVSS 8.8)

Pada admin/js/submissions-manager.js, nama pengadu, nomor telepon, dan deskripsi kasus diinterpolasi langsung ke tabel admin tanpa escaping HTML, serta nomor telepon tidak disamarkan (*unmasked*).

Dampak: Penyerang dapat mengirim payload dari form kontak publik untuk mengambil alih sesi admin saat admin memeriksa pengaduan masuk.

Remediasi: Gunakan fungsi escapeHtml() dan terapkan masking nomor telepon (0812-****-1234).
